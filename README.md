## 海外主机推荐先分清：你要的是 VPS 还是共享主机

很多推荐文章把 VPS 和虚拟主机混在一起讲，其实这是两种东西，选错类型后面全白搭。

**共享主机（Shared Hosting）**：你在一台服务器上和别人共享资源，用 cPanel 面板管理，适合跑 WordPress 博客、企业展示站这类标准网站。不用碰命令行，备份、SSL、一键建站都由面板处理。RackNerd 的共享主机跑在 LiteSpeed + NVMe 平台上，JetBackup 每日备份并复制到异地容灾机房，Softaculous 能一键装 WordPress 等 400 多个应用 [S20][S30]。

**VPS**：一台完整的虚拟服务器，给你 root 权限，想装什么装什么。适合自建应用、跑 Docker、部署 AI 工具、需要独立 IP 环境的场景。代价是所有运维自己来，RackNerd 明确标注服务性质是 unmanaged（无托管），出了问题只提供工单支持 [S19]。

简单判断：只是建网站选共享主机；要跑程序、要 root、要挂应用选 VPS。两边价格其实差不了几美元。
